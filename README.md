# Gardening-Website

## Project Overview
THis project I learned basic Laravel such as eloquent relationships, routing, authentication, to create a gardening web application that allows users to purchase and find out more about relative plants.

This project focused heavily on utilisation of Laravel features like creating a database and manipulating it based on information.

## Tasks & Responsibilities
For this individual university project I was responsible for creating a web application that uses a varietty of Laravel features to portray my understanding and skills. 

## Technical Tools
- Front-end: HTML & CSS.
- Back-end: PHP (Laravel)
- Development Environment: GitHub Codespaces.

## Key Features
- Dynamic search bar
- Eloquent ORM: Used  to establish categories which used One-to-many and user favourites using Many-to-many relationships between plants and users.
- Routing: routing webpages
- User Authentication & Authorisation: Secure login to ensure that correct users are logged in against database, and reliable accessability to ensure that established user roles can access certain features such as view,edit and add.
